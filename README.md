# Healthcare Hospital Website

A responsive multi-page healthcare website built using HTML, CSS, Bootstrap and JavaScript as part of a 4-member team.

## Live Demo
https://chandaniatraye.github.io/healthcare-hospital/

## Features
- Home Page
- About Page
- Departments Section
- Doctors Page
- Services Page
- Appointment Booking Form
- FAQs Section
- Contact Page with Map Integration

## Tech Stack
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Team
Built as part of a 4-member team project.
